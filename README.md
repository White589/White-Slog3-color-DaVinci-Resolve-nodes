# White-Slog3-color-DaVinci-Resolve-nodes
It is well known that the Slog3 gamma curve from Sony offers powerful color grading flexibility. If you are using a fourth-generation mirrorless camera (including the latest fifth-generation models, regardless of sensor size) released by Sony after 2020 that can capture 10-bit color depth, you will have a vast space to express your creative vision in DaVinci Resolve. It allows for significant color adjustments and stylization without easily breaking down. The Slog3 gray card also plays an important role in modern film workflows. That said, if you are an experienced colorist, this information may be unnecessary, and you might not even consider using this node setup. However, if you are a beginner using Sony mirrorless cameras, color grading can be extremely challenging. This node setup might save you a lot of trouble and serve as a great starting point to explore the wonderful world of color grading.
