# White-Slog3-color-DaVinci-Resolve-nodes
Sony S-Log3 color grading node presets for DaVinci Resolve，It is still in the testing phase, aiming to lower the threshold for new Sony users to shoot videos and fully utilize the potential of Sony's S-Log3 curve. Unlike LUTs, the color grading nodes within the software provide users with the maximum customization space.
